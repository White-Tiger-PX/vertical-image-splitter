# Vertical Image Splitter

**[English](README.md)** · [Русский](README.ru.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Português (Brasil)](README.pt_BR.md) · [Italiano](README.it.md) · [简体中文](README.zh_CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Türkçe](README.tr.md) · [Polski](README.pl.md)

Небольшая программа для разделения **любых изображений на две вертикальные части**. Обложка и корешок книги — только пример. Названия выходных файлов задаются вручную.

![Скриншот интерфейса Vertical Image Splitter](interface-illustration.png)

## Возможности

- Точный разрез: введи координату X в пикселях или перетащи красную линию на предпросмотре.
- Пакетная обработка файлов и папок. **Ctrl+клик** выделяет несколько строк для кнопки **«Сохранить выбранное»**.
- Перетаскивание строк для сортировки, применение одной доли ширины ко всем изображениям и отдельная настройка каждого разреза.
- Формат как у исходника либо PNG, TIFF, JPEG, WebP, BMP или GIF.
- Необязательные название серии и нумерация томов; без серии используются исходные имена.
- Исходники не изменяются; предыдущие результаты сохраняются в резервной копии.

## Установка и запуск

**Windows:** установи Python 3.10+ с Tkinter и открой `start.bat`. Если Pillow не установлен, BAT предложит его установку через pip.

**Linux/macOS:** нужен Python 3.10+ с Tkinter (в Linux часто требуется пакет `python3-tk`). Затем выполни:

```sh
python3 -m pip install -r requirements.txt
python3 cover_splitter.py
```

## Как пользоваться

1. Открой **Файл → Добавить изображения…** или **Добавить папку…**.
2. Выбери **Файл → Папка сохранения…**.
3. Впиши свои названия **левой** и **правой** частей. В русском интерфейсе пример по умолчанию — **«Обложка»** и **«Корешок»**.
4. Выбери формат: **«Как у исходника»** (по умолчанию), PNG, TIFF, JPEG, WebP, BMP или GIF.
5. При желании задай название серии и начальный номер тома в меню **«Названия»**.
6. Введи X в исходных пикселях или передвинь красную линию; кнопки ±1 px дают точную подстройку.
7. Выдели несколько строк через Ctrl (диапазон — Shift) и нажми **«Сохранить выбранное»** или **«Пересоздать все»**.

## Что сохраняется

Для файла `example.png` без серии создаётся следующая структура (названия указаны для английского интерфейса):

```text
output/
  example/
    example - Cover.png
    example - Spine.png
```

При заданной серии создаются папки с номерами томов, например `My Series. Vol. 1/` на английском. Названия обеих частей можно изменить, например на «Задняя обложка» и «Корешок».

## Обработка изображений

Масштабируется только предпросмотр, результат обрезается строго по пикселям исходника. JPEG сохраняется с quality=100, WebP — без потерь, TIFF — со сжатием без потерь. Многостраничные TIFF и анимации обрабатываются покадрово при совместимом формате. Изменение формата может повлиять на палитру, цветовой режим и метаданные. «Как у исходника» сохраняет формат, но не полностью идентичные байты.

## Язык и настройки

При первом запуске интерфейс **английский**, независимо от языка Windows. Переключение через меню **«Язык»** применяется сразу и сохраняется в `settings.json` вместе с файлами, разрезами, именами и форматом. Ручные названия частей не сбрасываются при смене языка. Автоопределения системного языка и онлайн-переводчиков нет.

## Приватность и резервные копии

Всё выполняется локально, файлы никуда не отправляются. Исходники не изменяются. Перед заменой результата старая версия копируется в датированную подпапку `Previous images/`. `settings.json` содержит локальные пути и исключён из Git через `.gitignore`. Папка программы должна разрешать запись.
